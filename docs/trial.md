# 使用与反馈

当前入口：**https://goalcal.zhang.sarl**。无需 ngrok 中转提示页。支持中文/英文；登录页可切换，登录后在设置选择语言。

公开注册填写用户名、邮箱、至少 6 位密码和时区；邮箱需唯一，登录支持用户名或邮箱。忘记密码时，在登录页选择「忘记密码」，按邮件中的链接设置新密码。旧版邀请码账号和数据没有自动并入新版。

建议体验：创建目标 → 回答必要澄清 → 审阅草稿 → 保存并安排 → 从今天页开始执行 → 签到完成或调整。日历支持手工创建、精确改期、拖拽与撤销；设置可配置时段并导入 `.ics` 文件。

反馈入口为 设置 → 意见反馈，填写 5–2000 字。系统收集操作编号、类型、耗时和错误类型；反馈正文存入业务数据库，不复制到运行日志。不要填写密码、密钥或他人的私密信息。

遇到页面打不开，记录发生时间、网络与页面表现交给维护者。维护者按 [生产手册](production.md) 查询诊断、反馈和备份。测试成功不代表所有地区网络长期稳定，运行依赖这台 Mac 的供电、登录与网络。
