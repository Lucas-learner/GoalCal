更新：2026-11-26。正式系统为 React 前端和 Python 模块化单体，使用一套 SQLite v16 数据库。

## 状态与数据

核心用户、目标、步骤、事件和签到继续使用领域表。Web 与双向同步扩展表包含 `web_drafts`、`web_proposals`、`web_operations`、`web_executions`、`web_requests`、`web_threads`、`habits`、`habit_rules`、`habit_occurrences`、`calendar_connections`、`calendar_sources`、`calendar_feeds`、`event_sync_links`、`sync_outbox`。`calendar_connections` 使用 Fernet 对称加密保存原生外部日历凭证，`events.sync_source_id` 按来源隔离同步日程，`sync_outbox` 与 `event_sync_links` 保证写锁外异步推送与双向防循环合并。用户表包含唯一邮箱。

LLM 不直接写库；输出经 schema 和业务校验。排期器是确定性函数，日期以用户时区计算，存储使用 UTC。所有 API 在用户边界下读取/写入，变更携带幂等键和资源版本。

## 部署边界

正式服务仅运行网关，React 静态文件与 API 同源。Streamlit 兼容模块仅用于回归或显式本机兼容运行，生产关闭其 HTTP/WebSocket 路由，不启动 8522。健康检查为 `/_goalcal/health`。

旧架构 PDF 已移入 `docs/archive/GoalCal-系统架构图-streamlit-2026-11-03.pdf`，不再作为当前架构附件。配置与维护见 [生产手册](production.md)。
