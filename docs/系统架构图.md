# GoalCal Web 系统架构

更新：2026-11-17。正式系统为 React 前端和 Python 模块化单体，使用一套 SQLite v8 数据库。


## 状态与数据

核心用户、目标、步骤、事件和签到继续使用领域表。新版增加 `web_drafts`、`web_proposals`、`web_operations`、`web_executions`、`web_requests`、`web_threads`，分别保存草稿、候选、可撤销操作、执行会话、请求幂等和助手线程。用户表包含唯一邮箱。

LLM 不直接写库；输出经 schema 和业务校验。排期器是确定性函数，日期以用户时区计算，存储使用 UTC。所有 API 在用户边界下读取/写入，变更携带幂等键和资源版本。

## 部署边界

正式服务仅运行网关，React 静态文件与 API 同源。Streamlit 兼容模块仅用于回归或显式本机兼容运行，生产关闭其 HTTP/WebSocket 路由，不启动 8522。健康检查为 `/_goalcal/health`。

旧架构 PDF 已移入 `docs/archive/GoalCal-系统架构图-streamlit-2026-11-03.pdf`，不再作为当前架构附件。配置与维护见 [生产手册](production.md)。
