# GoalCal Web 设计

当前实现以 `frontend/src/styles/tokens.css`、`global.css` 和 React 组件为准。旧 Streamlit 设计保存在 `archive/DESIGN-streamlit-2026-11-17.md`。

## 基础样式

| 用途 | Token / 值 |
|---|---|
| 背景 | `--bg: #fafaf8` |
| 表面 | `--surface: #fffefd` |
| 正文 | `--ink: #1d1d1f` |
| 主按钮 | `--accent: #303638` |
| 目标/选择辅助色 | `--blue: #6b7f89` |
| 卡片 / 控件圆角 | 13px / 9px |
| 字体 | 系统字体，含 PingFang SC |

## 页面与交互

- 今天：当前行动、下一步与恢复事项；按今日排期及目标优先顺序组织。
- 目标：目录与详情，阶段切换、步骤编辑、完成历史、归档（删除保留在 API 层）。
- 新目标：描述与期限、必要澄清、可修改草稿；确认后创建。
- 日历：FullCalendar，桌面周视图、移动单日，未排期步骤、事件详情与调整。
- 设置：账号与语言、可视化时段偏好、日历导入、指标与反馈。
- 助手：全局右侧抽屉/移动面板，候选保留时仍可输入，展示目标名；选择候选执行后可撤销。

错误保留输入，异步显示忙碌状态，危险操作确认，版本冲突要求重新获取。中英文案来自 `frontend/src/i18n`，服务端也按用户语言输出。
