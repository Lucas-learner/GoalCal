# GoalCal Web 设计

当前应用实现以 `frontend/src/styles/tokens.css`、`global.css` 和 React 组件为准。公开官网以 `frontend/src/intro/` 为准。

## 公开官网介绍页

- `/` 为匿名用户提供中英文单页介绍；已登录用户访问 `/` 重定向到 `/app/`。登录、注册继续使用 `/_goalcal/login` 与 `/_goalcal/register`。
- 视觉采用大标题、大留白、暖白与墨色、灰蓝和少量鼠尾草绿；全页统一使用暖白底（`#fafaf8`），首屏产品窗口底部以柔和渐隐衔接下方章节，结尾区与页脚采用羽化过渡的极浅暖灰绿收束，与首屏形成首尾呼应。毛玻璃导航、真实产品窗口和编号章节构成页面节奏，不依赖外部图片或视频。
- 产品理念与「如何工作」共用一个开场，不重复设置两个标题区。主叙事使用同一个“8 周内完成人生第一个 10 公里”示例，依次展示真实追问、修订后的可执行草稿、候选排期、当天执行与多目标周计划。每一步以编号功能名为唯一标题，只保留一句说明。日历同步、习惯、全局助手和主动提醒作为支撑能力；助手呈现目标与习惯起草、日程安排和计划调整，提醒同时说明系统日历闹钟、邮件摘要与每周复盘。
- 桌面使用局部 sticky 舞台与正常滚动联动；移动端改为顺序章节。支持 `prefers-reduced-motion`，减弱动态时直接显示最终内容。
- 首屏、五步主叙事和产品界面功能卡使用发布版真实 React 产品的本地 WebP 截图，中英文分别采集；提醒卡桌面端左列上方为标题与说明、下方接真实系统日历提醒设置，右列展示后端 `render_email_digest("weekly_review")` 渲染的真实每周复盘邮件，移动端改为单列顺序展示，不展示长设置页。主示例通过发布版 API 由 LLM 生成，不使用内部模板回退。每个故事步骤在全端使用同一张素材，需要同时呈现的控制或进度证据离线合成，不在运行时堆叠图片或按断点切换。故事素材使用相同像素密度与统一有效缩放，只通过裁切调整构图，不让窄图自动放大；03 与 04 来自同一次真实找时间、排期操作，使用相同高度的真实视口截图，不用补色或拼接对齐。移动端素材统一居中、统一比例，不对单步设置横向偏移；首屏在全端统一使用完整产品窗口截图，不按窄屏断点切图。官网只负责裁切、排版和切换，不重新设计产品内部控件，也不读取真实用户数据。产品 UI 调整后应同步更新 `frontend/src/intro/assets/` 中的截图。
- 构建入口为 `frontend/intro.html`，Vite 同时输出 `dist/index.html` 与 `dist/intro.html`；介绍页不加载 FullCalendar。

## 品牌标识与 Logo

GoalCal 采用 **地平线 G（Horizon G）** 作为统一品牌标志——*在平静的生活节奏里，让长期目标稳稳落地（A long-term goal, grounded in the calm rhythm of today）。*

- **几何隐喻**：
  1. **正圆与字母 G**：以同心正圆构成清晰的品牌首字母 **G**，象征目标与习惯沿着生活节律持续循环、稳步推进的轨道。
  2. **纯水平切口与横杠**：摒弃锐角箭头与斜切加速感，通篇使用平直水平切线，将长期目标收束为日历中清晰可达的「今日下一步」。
  3. **底部双水纹切片**：以两道微渐宽的水平留白切出三段平稳弧面，兼顾晨光倒影般的平静秩序与日历时间行／阶段拆解刻度。
- **视觉与工程规范**：
  - **无框留白、纯粹单色**：不使用厚重封闭外框或浮夸渐变，主图形仅以深墨（`#1d1d1f`）与暖白（`#f0f0ee` / `#fafaf8`）呈现，应用与官网内通过 `currentColor` 自动匹配文字与主题色（官网页脚继承 `#1d1d1f`）。
  - **纯解析矢量路径**：图形仅由 4 条无遮罩 ID 的解析 `<path>` 构成（`viewBox="14 14 92 92"`），避免同页多实例碰撞并在 `16px` 标签页至 `180px` 桌面图标全尺寸下保持锐利。
- **实现与资源位置**：
  - 前端共享组件：`frontend/src/components/BrandMark.tsx`（接入官网导航/页脚与 Web 应用侧边栏）。
  - 静态图标：`frontend/public/favicon.svg`（内置浅/深色 `prefers-color-scheme` 适配）、`frontend/public/favicon.ico`（16px / 32px）、`frontend/public/apple-touch-icon.png`（180px）。
  - 登录/注册网关：`goalcal/auth_proxy.py` 内联同款 `<svg>` 并通过 `/favicon.svg`、`/favicon.ico`、`/apple-touch-icon.png` 公开提供图标资源。

## 页面与交互

- 今天：当前行动、下一步、同步冲突重排提示与恢复事项；按今日排期及目标优先顺序组织。
- 目标：目录与详情，阶段切换、步骤编辑、完成历史、归档。已归档的目标和习惯可在「设置 → 已归档」中确认删除。
- 习惯：桌面和移动端独立入口。页头、空状态、目录与详情、创建表单、进度条和下一步卡片沿用目标页布局。规则预览、周期进度与补记适配重复执行。见 [习惯功能设计](habits-design.md)。
- 新目标：描述与期限、必要澄清、可修改草稿；确认后创建。
- 日历：FullCalendar，桌面周视图、移动单日，点击周视图日期可进入当天；顶部操作区提供「日历同步」快捷入口，上方展示外部日历来源色点筛选条与冲突一键改期提示，并在存在全天日程时展开全天槽。移动端默认收起「尚未安排」，通过表单排期；桌面精细指针保留拖拽。日期导航和周／日切换在独立工具栏内。
- 设置：账号、语言、外观、可视化时段偏好、已归档、日历同步（Apple/Google 原生双向同步 + `.ics` 链接自动拉取 + 折叠手动导入 + 只读 `.ics` 导出）、提醒与通知、意见反馈。外观支持浅色、深色和跟随系统，默认跟随系统。日历弹窗对外部同步事件展示来源色点、名称与「仅展示」标识。
- 助手：全局右侧抽屉/移动面板，候选保留时仍可输入，展示目标名；选择候选执行后可撤销。

错误保留输入，异步显示忙碌状态，危险操作确认，版本冲突要求重新获取。中英文案来自 `frontend/src/i18n`，服务端也按用户语言输出。
