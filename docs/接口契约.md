# GoalCal Web 接口契约

当前源码依据：`goalcal/web/http.py` 的 `SPECS`、`schemas.py`、前端 `api/types.ts`。基础路径 `/api/v1`，同源 HttpOnly 会话 Cookie。旧 Action/领域函数说明保存在 [历史契约](archive/接口契约-streamlit-2026-11-17.md)。

## 通用规则

写请求为 JSON，必须携带合法同源 `Origin` 和 `Idempotency-Key`；同一次操作重试复用键，新的操作使用新键。受版本保护的资源带 `version`，冲突返回 409。日期时间传带时区的 ISO 字符串，业务按用户时区计算，库内存 UTC。用户身份来自认证，不接受请求任意指定租户。

未认证 401，非法来源 403，不存在/不可访问 404，输入错误 422；具体错误对象由 `web/http.py` 的 `error` 定义。前端展示本地化错误并保留表单，不能把错误当作成功。

## 接口组

| 路径（省略基础路径） | 方法 | 用途 |
|---|---|---|
| `/me` | GET / PATCH | 当前用户、语言偏好；PATCH 尚不支持时区 |
| `/today` | GET | 今日下一步、执行与恢复信息 |
| `/goal-intake`、`/goal-drafts` | POST | 澄清与计划预览 |
| `/goals`、`/goals/{id}` | GET / POST / PATCH / DELETE（按资源） | 目标查询、创建、更新、删除 |
| `/goals/{id}/refill`、`/steps/{id}` | POST / PATCH | 后续步骤与步骤编辑 |
| `/calendar/events`、`/events/{id}` | GET / POST / PATCH | 事件列表、创建、移动 |
| `/events/{id}/cancel` | POST | 取消事件 |
| `/steps/{id}/proposals`、`/proposals/{id}/accept` | POST | 排期候选与接受 |
| `/steps/{id}/schedule` | POST | 指定时间排期 |
| `/operations/{id}/undo` | POST | 撤销可撤销操作 |
| `/events/{id}/start`、`/steps/{id}/start` | POST | 开始执行 |
| `/execution-sessions/{id}/checkin`、`/events/{id}/checkin` | POST | 完成、部分或调整签到 |
| `/preferences/availability` | GET / PUT | 可用、保护、偏好时段、缓冲与上限 |
| `/assistant`、`/assistant/turns`、`/assistant/clear` | GET / POST | 线程读取、对话、清空 |
| `/calendar/import` | POST | ICS 文本导入，当前无订阅 URL 拉取入口 |
| `/metrics`、`/feedback` | GET / POST | 指标读取、反馈提交 |

认证页面位于 `/_goalcal/login`、`/_goalcal/register`，退出为 `POST /_goalcal/logout`。登录表单额外使用 CSRF 表单令牌。`/_goalcal/health` 检查 Web 就绪状态，成功 200，未就绪 503。

契约修改需同步前端类型、客户端及 API/业务/E2E 测试；不要直接暴露旧 `Conversation.state_json` 为 API 返回值。
