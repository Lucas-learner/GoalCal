# 历史 prompt 评测

这里保留滚动续阶规划的对照脚本、原始输出和报告，不是当前 Web 版本的验收套件。当前回归入口见 [项目 README](../../README.md)。报告中的模型、日期和结论仅对应当时实验，不因脚本更新而自动成为新版结果。

`run_*.py` 会调用真实模型并产生费用；仅在需要重新评估 prompt 时手动运行。环境文件必须通过 `GOALCAL_ENV_FILE` 显式指定，或直接提供 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL` 等环境变量。默认不读取根目录 `.env`，数据库强制为内存库，生产模式关闭。

例如从仓库根目录运行：

```sh
GOALCAL_ENV_FILE=/绝对路径/开发模型环境文件 .venv/bin/python bench/prompt_eval/run_eval.py
```

脚本会覆盖同目录相应 JSONL；`analyze_*.py` 会根据现有 JSONL 覆盖报告。重新生成前保留原始实验文件，并保证分析使用的模型配置与生成记录一致；分析脚本不能从当前环境自动证明历史模型身份。本次仓库清理只修复路径与环境隔离，没有重新调用模型或重写历史结果。
